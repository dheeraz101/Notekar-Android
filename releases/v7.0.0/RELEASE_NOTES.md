## Notekar v7.0.0 (Stable Release)

Signed release - built automatically from the main release channel.

### What's New & Major Highlights

- **Apple HIG & iOS UI/UX Redesign**:
    - Top-floating iOS Dynamic Island pill toast notifications with tactile haptic feedback.
    - Apple HIG sheet drag grabber handle (`36x5pt`), 38pt top corner radius (`radius: 38`), and
      rubberband spring dismiss physics.
    - Standardized `CupertinoActivityIndicator` spinners across Backup, Diagnostics, and Update
      Center action buttons.
    - Apple Health `IosActivityRingPainter` circular glowing activity arcs for sobriety counters.
- **Modernized App Icon Suite & Branded Editions**:
    - 6 custom branded logo editions: *Default Classic*, *Amethyst Nebula*, *Midnight Glass*, *Solar
      Emerald*, *Nordic Frost*, and *Sunset Gold*.
    - Redesigned icon gallery grid with enlarged previews and standalone upgrade card.
- **Sobriety Milestones & Native Share Sheet**:
    - Export milestone card images directly to Android share chooser (`shareText`).
    - Zero-delay milestone celebration dialogs with one-shot confetti particles.
    - Vertical milestone trails and customizable milestone themes.
- **Full-Length Search Notes**:
    - Full length display of all recorded notes by default in Search Notes (sorted newest first).
    - Dedicated search navigation controller eliminating header search bar collisions.
- **Logging & Directional Badges**:
    - 2-digit single numbering mode (`01`, `02`, `03`...), daily auto-reset, and moment count on
      save.
    - Directional badges with `IN`/`OUT` arrow indicator icons.
- **Local Backups Manager & Developer Options**:
    - Complete local backup manager with individual Restore and Delete options.
    - Grouped Developer Options (Diagnostics, Device Health, Network Monitor, Commits) under
      Advanced settings.
