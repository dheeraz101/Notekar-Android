## Notekar v5.1.2

Signed release - built automatically from the branch.

### What's Changed

* **Hardware-Backed DB Encryption**: Secured database storage using 256-bit AES encryption keys
  derived inside the native Android Keystore.
* **Persistent Lock-Screen Action Notification**: Add sticky low-priority status bar controls to
  check IN/OUT or write notes directly from the lock screen.
* **Apple-Style Security Onboarding**: Seamlessly showcases cryptographic upgrade details to users.
* **Status Bar Quick Settings Tile**: Add new notes/logs from your notification shade without
  opening the main app.
* **Dynamic App Launcher Shortcuts**: Long-press icon options for instant background log actions.
* **App Switcher Privacy Obfuscation**: Prevent screen previews and screenshot capture when
  minimized.
* **List Scroll Layout Optimization**: GPU repaint boundary caching for high-speed scrolling on long
  history lists.
